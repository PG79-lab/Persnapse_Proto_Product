# 명함 외곽 모델 LC100 우선 선택

후속 연결: [0023 OCR 전 원근 보정](0023-card-rectification-before-ocr.md)에서
일반 촬영 경로까지 연결했다. 아래 운영 경로 미연결 상태는 이 결정 당시의 기록이다.

2026-10-13 사용자 요청에 따라 DocAligner LC100을 우선 사용할 모델로 결정한다.
`card_recognition/model-policy.ts`에 선택을 기록하고 통합 `/#cards` 로컬 테스트 패널의 기본값에 적용한다. 기존 T8 후보 우선순위보다 이 결정이 우선한다.

실제 사진 27장에서 LC100은 기하적으로 유효한 외곽 23장(85.2%), 검토 필요 4장, 실행 오류 0건이었다. 이는 정답 정확도가 아니다. 정답 테두리 검수와 모바일 지연 검증은 미완료이며 운영 촬영 자동 복원 경로는 아직 기존 OpenCV다.

단일 HTML 비교 파일에는 27장 사진, 81개 검출 결과, 측정 CSV와 요약, 테두리 편집 및 임시 평가를 포함한다. 네트워크 없이 열며 정답/평가 JSON을 다운로드·재입력한다. 개인 사진을 포함하므로 산출물은 Git에서 제외된 output에만 저장한다.

촬영 경로 연결 시 원본 유지 → LC100 Worker 검출 → 유효성 검사 → 원근 복원 → 미리보기 확인 순서로 연결한다. 누락·잘못된 외곽은 수동 네 점 편집으로 보완한다. 확인된 복원본을 기존 OCR에 넘기며 OCR 모델/필드 저장 정책은 별도로 유지한다.
