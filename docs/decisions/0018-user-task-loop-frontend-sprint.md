# 0018 — 사용자 과업 루프 중심의 프론트엔드 스프린트

- 날짜: 2026-10-10
- 작업 위치: `D:\Persnapse\persnapse-mvp`
- 기준: [결정 0017](0017-relationship-memory-experience.md), [MVP 정의](../product/mvp-definition-v0.1.md)의 Capture → Confirm → Recall → Action.

## 결정

사용자 테스트 전에는 서버 구조·모델 라우팅보다 핵심 과업의 이해와 완수에 투자한다. 화면의 기능 수나 카드 수로 성공을 판단하지 않는다. 처음 방문한 사용자가 명함을 등록하고, 저장된 기억을 근거와 함께 찾아, 다음 행동으로 넘어가는 과정을 판단 기준으로 삼는다.

| 관찰                                                       | 적용                                                     | 사용자에게 확인할 것                               |
| ---------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------- |
| 용도별 인맥 카드가 모두 0이면 실제 인맥이 없는 것처럼 보임 | 값이 있는 용도만 요약하고 미분류 상태에 정리 경로 제공   | 데이터가 없는 상태와 분류가 없는 상태를 구별하는가 |
| 명함 빈 화면의 촬영·업로드 버튼이 중복됨                   | 입력을 한곳에 두고 검토 단계·저장 후 인맥/기억 경로 연결 | 첫 행동과 저장 후 다음 행동을 스스로 찾는가        |
| 인맥·만남이 많으면 지도 이름이 겹침                        | 인맥 8명씩 탐색, 전체 보기와 만남 표시를 별도 선택       | 원하는 사람을 지도에서 찾을 수 있는가              |
| AI의 근거와 후속 업무가 결과에서 멀리 있음                 | 첫 근거 노출, 인물의 할 일 화면으로 이동                 | 결과를 신뢰하고 후속 업무로 이어지는가             |
| 모바일 AI 예시가 입력창에 가림                             | 예시·입력창·전송 버튼의 화면 내 배치 수정                | 작은 화면에서 질문을 막힘없이 시작하는가           |
| 녹음한 음성이 새로고침 뒤 사라짐                           | 브라우저 IndexedDB에 음성 파일과 메타데이터 보관         | 로컬 보관 범위를 이해하고 재방문 시 찾는가         |

녹음 파일은 **현재 브라우저에만** 보관된다. 공유 서버에 저장된 텍스트 기록과 혼동하지 않도록 안내한다. STT, OCR 실제 정확도, AI 검색 지연, 메일 생성 품질은 이번 프론트엔드 개선으로 검증되거나 해결된 것으로 취급하지 않는다. 기존 팀 공유 Preview는 그대로 유지한다.

## 사용자 평가 게이트

팀원 6명에게 설명 없이 아래 과업을 실행하게 하고, 진행자의 힌트·실패·잘못 저장된 필드를 별도로 기록한다. 아래 목표는 **통과 기준**이며 아직 달성 결과가 아니다.

1. 명함 업로드/촬영 → 추출값 수정 → 기존/새 인맥 결정 → 저장: 6명 중 5명 이상이 안내 없이 완료, 치명적인 잘못된 인맥 연결 0건.
2. 이름을 모르는 과거 만남을 AI에서 찾기 → 첫 근거 확인 → 해당 인물로 이동: 6명 중 5명 이상이 올바른 인물을 찾고 근거를 자기 말로 설명.
3. 기한 지난 약속 확인 → 해당 인물의 할 일 완료: 6명 중 5명 이상이 안내 없이 완료.
4. 지도에서 특정 인물을 찾고 만남을 탐색: 6명 중 5명 이상이 화면의 보기 범위와 전체 보기의 차이를 이해.
5. 모바일 390px에서 위 과업을 반복: 가려진 주요 버튼 0건, 가로 스크롤 0건.

과업별 소요 시간, 막힌 단계, 잘못 클릭한 횟수, 신뢰도 1–5점과 개선 제안을 함께 기록한다. 이를 충족하기 전에는 제품 경험을 ‘매우 높음’으로 보고하지 않는다. [구현·자동 검증 기록](../operations/ux-task-loop-sprint-2026-10-10.md).
