# GitHub 인수인계 준비본 분리

날짜: 2026-10-25

사용자 승인에 따라 원본을 보존하고 별도 로컬 clone에서 인수인계 준비를 진행한다. 기존 main 이력은 유지하며 과거 실험 worktree를 병합하지 않는다.

준비 범위는 실행 문서, 모델 패키지와 무결성 확인, 개인정보 없는 화면 예시, 재현 가능한 기본 검증이다. 제품 기능과 실제 DB·배포 환경은 바꾸지 않는다. GitHub 업로드는 결과 검토와 저장소 지정 후 진행한다.

실제 서비스 데이터가 필요한 E2E 2개는 `@integration`으로 분리한다. 기본 브라우저 검증은 격리 환경변수와 합성 데이터로 실행하며 그래프 전용 검사는 별도 설정으로 실행한다. 이를 통해 단순 설치 검사와 실제 서비스 연결 검사의 의미를 구분한다.

모델 바이너리는 Git 대신 Release용 ZIP으로 전달하고 기존 manifest의 크기·SHA-256으로 검증한다. 라이선스·NOTICE를 동봉한다. 문서의 원본 화면은 원본 폴더에 보존하고 준비본에는 합성 데이터로 다시 촬영한 화면과 이를 내장한 HTML만 포함한다.
