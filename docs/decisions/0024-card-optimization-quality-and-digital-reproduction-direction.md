# 명함 최적화·품질 평가 이후 디지털 재현으로 진행

- 기록일: 2026-10-13
- 상태: 사용자 확정 작업 방향 / 20분 실행안 승인·탐색 구현 수행
- 근거: 사용자가 속도 최적화와 품질 평가를 적당한 규모로 진행하고, 이후 원본 보존·이미지 처리·명함 디지털 재현에 집중하도록 지시했다.

## 확정 방향

1. LC100 파이프라인의 테두리 후처리와 모델·Worker 재사용을 우선 최적화한다.
2. 실제 사진 27장의 정답 테두리를 작성해 IoU·모서리 오차를 측정하고, 보정 전후 실제 OCR을 비교한다.
3. 이후 촬영 원본 보존과 재처리 가능한 자산 구조를 개선한다.
4. 필터링·노이즈 제거·대비 조정·업스케일링의 효과를 검토하고 이미지 처리를 고도화한다.
5. 중요한 후속 목표는 로고·글꼴·색상·배치를 반영하여 원본 도안에 가까운 명함 디자인을 프론트엔드에서 재구성하는 **디지털 재현**이다.

1·2단계는 빠른 개선과 측정 가능한 결과를 목표로 제한한다. 초기 설계의 전체 품질 gate 달성을 위해 이 단계의 범위를 계속 확대하지 않는다. LC100 기본 모델, 통합 `/#cards`, 보정 이미지 확인 후 OCR 흐름을 유지한다.

### 사용자 피드백 반영: 20분 탐색 작업

사용자는 구현 착수부터 보고까지 **20분 이내**의 작은 개선·탐색 작업으로 축소했다. 앞선 1~2 작업일 계획은 대체한다. 이번에는 결과를 유지하는 후처리 개선, 대표 사례 평가, 비스듬한 촬영의 원근 보정과 보정본 90도 회전 지원을 우선한다. 자동 실패는 수동 모서리 편집으로 복구하고, 방향은 사용자 회전으로 확정한다.

27장 전체 GT/OCR 평가와 Worker·모델 재사용 구현은 후속 후보로 남긴다. 이번 잠정 정답은 최대 3장, 실제 OCR은 준비된 환경에서 최대 4회 호출 시도로 제한한다. 정식 품질 gate와 모든 각도 자동 성공을 주장하지 않는다. 후속 원본 보존·이미지 처리·디지털 재현 방향은 유지한다.

## 승인과 범위

사용자가 수정된 20분 실행안에 OK하여 구현·대표 평가를 진행했다. [실행 결과](../operations/card-quick-optimization-results-2026-10-13.md)를 확인한다. 후속 대규모 최적화·평가는 별도 범위다.

3~5단계는 후속 방향이며 세부 구현 설계는 아직 확정하지 않았다. 현재의 원근 보정 이미지는 디지털 재현 결과가 아니다. 원본 자산 관리가 일부 구현되어 있으나, 무손실 촬영 원본 영구 보존과 장기 재처리 정책까지 완성한 것으로 간주하지 않는다.
