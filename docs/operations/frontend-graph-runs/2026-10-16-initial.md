- Node: 24.20.0, Next.js 16.3.8, Chromium 153.0.8010.12. lockfile 기준 `npm ci --no-audit --no-fund` 완료. 패키지 버전·lockfile 변경 없음.
- `.env.local`과 다른 worktree 의존성·빌드 산출물은 복사하지 않는다.
- 일반 브라우저 미리보기와 UI E2E는 합성 fixture를 사용한다. `PERSNAPSE_GRAPH_PREVIEW=1`이고 Vercel이 아닌 환경에서만 허용한다. 기존 prototype 접근 검사 후 `/api/workspace`, 카드 목록, Recall 준비 상태만 합성 조회를 제공하고 나머지 API는 `501 PREVIEW_OPERATION_UNAVAILABLE`로 차단한다. 저장 성공으로 표시하지 않는다.
- 개발 port 4316, production UI E2E port 4315. STT의 잘못된 입력 검사는 preview 우회를 끈 별도 port 4317에서 실제 validation handler에 도달한다. 이 서버는 합성 필수 설정, 연결 불가능한 로컬 DB 주소, 지원하지 않는 STT 모델을 사용한다. workspace 조회는 브라우저에서 mock하며 유료 provider 호출은 하지 않는다.
- `playwright.graph.config.ts`의 두 서버는 `reuseExistingServer=false`다. `.next` 충돌을 피하려고 production build/E2E 동안 개발 미리보기를 중단하고 종료 후 복구한다.
- 실제 DB·LLM·OCR·STT 연결을 검증한 것으로 보고하지 않는다.

- 기존 Graph는 임의 self 노드와 모든 고립 인물 사이에 선을 생성한다. 새 어댑터에서 실제 참석·소개 기록만 사용한다.

`선택`, `탐색 중심`, `패널 열림`, `카메라`, `좌표`를 분리했다. 선택과 상세 닫기로 중심·좌표를 바꾸지 않는다. 초기 2-hop 최대 12개, 전체 보기 최초 20개의 표시 제한을 안내하며 나머지는 목록에서 접근할 수 있다. 확장은 실제 이웃을 최대 10개씩 추가한다. 전체 보기라는 이름이 전체 데이터가 항상 동시에 그려짐을 뜻하지 않도록 범위·숨김 수를 함께 표시한다.

동명이인은 회사·직무와 ID로 구분한다. 소개 선은 현재 저장된 소개 기록을 의미하며 친밀도나 행사 참석을 추정하지 않는다. 저장 원문은 ID로 현재 상태에서 다시 찾으므로 새로고침 시 삭제된 메모·인물의 과거 본문을 계속 보여 주지 않는다.

### 회귀 검사 보정 사유

- 기존 업무 테스트의 bare `/` 진입을 `/#todos`로 명시하고 Graph 기본 진입 기대만 변경했다.
- 기존 Graph의 8명 paging·자동 숨김 기대를 새 slice/확장/전체 목록 동작에 맞췄다. 높은 차수, 숨김 안내, 추가 인물 접근 검증을 유지했다.
- 명함 E2E는 기존 UI에 있는 `OCR 전 모서리 직접 지정` 클릭을 추가하고 보정 대기 시간을 20초로 조정했다. 승인 전 OCR 미호출 assertion은 유지했다.
- 녹음 E2E의 이미 오래된 안내 문구를 현재 RecordingPage에 맞췄다. 실제 마이크 입력·결과 검토 후 반영 검증은 유지했다.
- 명함 로컬 추론 검사를 위해 저장소 manifest에 고정된 공개 ONNX 모델 두 개를 다운로드하고 bytes/SHA-256 확인 후 기존 copy script를 실행했다. 모델·알고리즘·manifest 수정 없음. 다운로드/복사 산출물은 ignored 경로다.

```powershell
Set-Location D:\Persnapse\worktrees\persnapse-frontend-graph-review
$env:PERSNAPSE_GRAPH_PREVIEW = '1'
npm run dev -- --hostname 127.0.0.1 --port 4316
```

접속 주소: <http://127.0.0.1:4316/#map>. 합성 fixture `FG-FIXTURE-01`이고 새로고침으로 원상 복구된다. 기록 입력 화면에는 접근할 수 있지만 서버 저장·OCR·STT·AI 실행은 차단되어 있다. 실제 작업 가능 여부를 확인하는 화면으로 오인하지 않는다. 마지막 확인: 2026-10-16 05:45 KST, 127.0.0.1:4316 LISTEN, 소유 Next server PID 21060. 작업 cwd·branch는 위와 같고 exec 세션 90368에서 실행 중이다. 재시작 후 일반 브라우저에서 HTTP 200, FG-FIXTURE-01, 인물 8명·초기 노드 5개, 가로 overflow 없음·runtime error 0을 확인했다. 4315/4317 E2E 서버는 검사 후 종료했다. PID는 재시작 때 달라지므로 정지 전에 cwd/command·port를 다시 확인한다.
