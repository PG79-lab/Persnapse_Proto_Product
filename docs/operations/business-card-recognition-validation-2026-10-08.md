# 명함 인식 스프린트 검증 · 2026-10-08

## 적용 내용

- 카메라 가이드와 실제 비디오 크롭을 같은 좌표계로 계산한다. 지원 브라우저에서는 `ImageCapture.takePhoto()`를 우선 사용하고, 촬영 이미지 확인·재촬영 후 OCR을 시작한다. 실제 카메라 해상도가 낮으면 경고한다.
- 표시용 이미지를 인위적으로 확대하지 않는다. OCR에는 최대 2560px 긴 변의 원본 변형을 보낸다. 재시도와 캐시도 원본 자산 SHA를 사용한다.
- OpenAI 이미지 직접 추출 후보를 동일한 `BusinessCardExtractionV1` 스키마로 추가했다. `BUSINESS_CARD_OCR_PROVIDER=openai`일 때만 실제 경로로 사용한다. 기존 기본값은 `naver_clova`다. 두 제공자는 비용 예약 범위를 분리한다.
- 검토 화면은 원본 사진과 디지털 정보를 별도로 보여주며, 이름·회사·직함·이메일·전화번호를 우선 배치한다. 주소·부서·웹사이트는 접어서 볼 수 있다.
- 원본과 표시 이미지 업로드를 병렬화하고, 한쪽만 성공한 경우 성공한 자산을 정리한다. 브라우저 `performance` 항목과 HTTP `Server-Timing`으로 전처리·업로드/OCR 구간을 관찰할 수 있다.

## 합성 명함 비교

원본 카드 2종과 가우시안 노이즈(표준편차 18, JPEG 품질 0.72)를 적용한 카드 2종에 대해 제공자별 4회씩 호출했다. 비교 필드는 이름·회사·직함·이메일·전화번호이며 필드 단위 정확 일치다.

| 경로                                     | 일치 필드 | 평균 호출 시간 | 조건별 일치        |
| ---------------------------------------- | --------: | -------------: | ------------------ |
| CLOVA General + 현행 파서                |     14/20 |        1,078ms | 3/5, 4/5, 4/5, 3/5 |
| OpenAI 이미지 직접 추출 (`gpt-5.6-luna`) |     20/20 |        2,037ms | 5/5, 5/5, 5/5, 5/5 |

이는 **합성 4장에 대한 스모크 비교**다. 실제 명함 정확도, 한국어 디자인 다양성, p50/p95 및 모바일 총 소요 시간을 입증하지 않는다. [공개 94건 후보](https://huggingface.co/datasets/JoyboyBrian/structured_images_easy)는 실명·연락처를 포함하고 이용 허가와 원본 출처가 명확하지 않아 외부 API 검증에 사용하지 않았다. 실제 명함 검증에는 사용 허가가 분명한 이미지와 수정 완료 정답 100건가량이 필요하다.

로컬 OpenAI 선택 경로의 DB·Storage 포함 실동작 검증도 두 차례 통과했다. OCR 구간은 각각 5,168ms와 3,147ms였으며, 두 번째 실행의 제공자 호출은 2,955ms였다. 검증용 인물·만남·이미지 레코드는 종료 후 0건으로 정리됐다. 5초 목표는 첫 실행에서 넘었으므로 달성으로 판정하지 않는다.

## 운영 선택

로컬 `.env.local`은 이번 스프린트 확인용으로 `BUSINESS_CARD_OCR_PROVIDER=openai`를 설정했다. 배포 환경에서는 같은 변수를 명시하지 않으면 기존 CLOVA 경로를 유지한다. OpenAI 키는 서버에만 둔다. 실제 명함 검증에서 오탐·누락과 지연을 확인하기 전에는 합성 결과를 제품 정확도로 제시하지 않는다.
