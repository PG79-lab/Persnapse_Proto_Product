# 사용자 테스트 가능 횟수와 호출 정책 — 2026-09-22

## 적용 정책

사용자가 웹앱 누적 한도 해제를 명시적으로 요청했다. 새 버전은 AI·명함 OCR 모두 일/월 총횟수 제한이 없다. AI는 workspace 전체에서 최근 60초간 60회 모델 요청, OCR은 제공자 범위 전체에서 최근 60초간 20회와 최소 1초 간격으로 단기 폭주만 차단한다. 평상시 총횟수 제한은 없으며 제공자 잔액·요금·요청 속도 제한은 별개다.

- 변경 전 마지막 직접 확인: 일/월 90/90 요청 사용, 앱 잔여 0.
- 새 버전에서 오래된 누적 90회는 차단 사유가 아니다. 호출 이력은 삭제하지 않는다.
- 회상만 반복하면 앱 분당 모델 호출 방어는 최대 15회 회상 분량이다. 새 입력+저장+회상은 최대 6회 모델 요청이므로 10회 분량이다. 이는 처리량 보장이나 총사용 상한이 아니다. 여러 사용자와 작업이 같은 창을 공유하고 제공자 속도 제한이 더 낮을 수 있다.

## $10 기준 추정

OpenAI 잔액이 현재 $10이라고 가정한 계산이다. 실제 계정 잔액을 조회하지 않았으며 기존 사용액과 다른 프로젝트 사용액은 차감하지 않았다.

| 사용자 테스트 단위                       | OpenAI 모델 요청          | 실측 토큰 기반 1회 비용 | $10 기준 가능 횟수 |
| ---------------------------------------- | ------------------------- | ----------------------- | ------------------ |
| 저장된 기억에 질문·회상                  | 최대 2회, Voyage 별도 2회 | $0.01168~$0.02678       | 약 373~856회       |
| 새 텍스트 맥락 입력·수정·저장 → 회상 1회 | 최대 3회, Voyage 별도 3회 | $0.01190~$0.02719       | 약 367~839회       |

- 근거: 완료된 회상 11회, 맥락 구조화 4회에서 제공자가 반환한 input/output 토큰. 중간 예산 차단된 회상은 표본에서 제외했다. 회상 평균 $0.01869, 맥락 평균 $0.000343. 1사이클 조합 범위는 각 표본 min/max 합으로 계산한 예상치이며 전체 사이클의 실제 청구 샘플이 아니다.
- 모델 단가 재확인: [Luna 공식 문서](https://developers.openai.com/api/docs/models/gpt-5.6-luna) 입력 $0.20/출력 $1.20, [Terra 공식 문서](https://developers.openai.com/api/docs/models/gpt-5.6-terra) 입력 $2/출력 $12, 각각 100만 토큰 기준.
- 캐시 할인 미반영. 데이터·근거·답변 길이가 늘면 비용이 커지고 횟수가 줄어든다. 보장 횟수가 아니다.
- Voyage와 Naver OCR은 OpenAI 크레딧에서 차감되지 않는다. 표의 텍스트 테스트는 Naver OCR을 호출하지 않는다. 명함 이미지까지 포함한 횟수는 Naver 계정 요금·잔액 미확인으로 확정하지 않는다.
- 현재 잔액이 B달러면 표의 횟수 × B/10으로 환산할 수 있다.
