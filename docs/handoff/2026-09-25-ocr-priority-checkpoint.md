# OCR 고도화 전 개발 기준점 — 2026-09-25

## 결정과 작업 순서

사용자가 현재 구현의 로컬 커밋을 승인했다. 작업 경로는 D:/Persnapse/persnapse-mvp이며 기존 사용자 데이터·로컬 설정·미커밋 결과물을 보존한다. push는 별도 요청 전 수행하지 않는다.

1. 현재 명함 입력·OCR·저장·실제 AI 회상·안전장치 구현과 관련 테스트를 개발 기준점으로 보존한다. 제품 완성이나 결함 해결을 의미하지 않는다.
2. 다음 개발 우선순위는 OCR 고도화: 실제 명함 입력, 인식 정확도, 이름·회사·직책 등 구조화, 처리 성능과 수정 경험이다.
3. 실제 명함과 맥락을 축적한 뒤 회상 품질을 추가 검증·개선한다. 가상 인물 기반 검증을 실제 사용자 품질로 확대 해석하지 않는다.
4. 대규모 검토와 필요한 리팩토링은 MVP 최종본 마무리 단계에서 진행한다. 현재는 핵심 사용자 흐름에 필요한 제한된 변경을 우선한다.

## 현재 구현과 알려진 한계

- 초기 9월 22일 인계의 mock·로컬 Recall 설명 이후 실제 OpenAI/Voyage 회상 연결과 단기 호출 제한이 구현됐다. ADR 0011·0012와 운영 기록을 함께 읽는다.
- SEARCH_NOT_READY 장애는 미해결이다. 9월 22일 실제 DB 진단에서 16명 중 13명 ready, 3명 pending을 확인했다. 3건은 mock 구조화 저장 기록과 연결되어 있었으며 해당 저장의 배포 출처는 확정하지 못했다. 이 수치를 현재 DB 상태로 취급하지 않는다.
- 현재 코드는 mock 모드에서 색인 생성을 건너뛰고, 미준비 문서 하나로 전체 live 회상을 차단한다. 사용자용 검색 준비 재시도 흐름이 없다. 실제 명함 기반 회상 시험 전에 이 차단 문제를 해소해야 한다.
- 과거 전체 흐름 검증의 회상 지연은 약 9.9초로 목표 6초에 미달했다. 기본 Graph와 음성 입력/STT는 원본 필수 범위이며 아직 미구현이다.
- 테스트 통과·제공자 연결·실제 사용자 성공 경험을 구분하고, 기능·현실 성능·설계 일치·사용자 관점으로 주요 단계를 평가한다.
