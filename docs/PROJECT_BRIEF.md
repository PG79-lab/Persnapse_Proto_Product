# Persnapse MVP — 제품·시스템 핵심 요약

> 기준: 2026-10-11 · 통합 레포 `D:\Persnapse\persnapse-mvp` · 구현 기준 커밋 `2ccd6a4`

## 1. 무엇을 만드는가

Persnapse는 외부 사람을 자주 만나는 사용자를 위한 **관계 기억 도구**다. 명함과 만남 맥락을 확인 후 저장하고, 나중에 이름을 잊어도 행사·회사·주제·약속을 단서로 사람을 **근거와 함께 회상**하여 후속 행동으로 이어지게 한다.

핵심 사용자 흐름: **명함/만남 기록 → 추출·구조화 결과 검토 → 인맥 저장 → 자연어 회상·근거 확인 → 할 일 처리**. 현재 판단 기준은 기능 수보다 처음 쓰는 사람이 이 흐름을 설명 없이 완수하는지다.

- 2026-10-10 기준: 타입 검사·프로덕션 빌드·포맷 검사 통과, lint 오류 0건(이미지 권고 2건), 단위 테스트 **207/207**, Edge E2E **28/28**. E2E는 합성 workspace/AI 응답을 사용한다.
- 원격 Preview에서 `/`, `/api/workspace`, `/api/recall/preparation` 비인증 HTTP 200과 서버 데이터 조회를 확인했다. 당시 인맥 17명·만남 21건·업무 10건, 검색 준비 17/17이었다. 이 수치는 변할 수 있다.

- 실사용자 6명의 명함 등록·회상·업무·지도 과업 성공률, 신뢰도, 반복 사용 의도는 **미측정**이다. 따라서 UX가 ‘매우 높음’에 도달했다고 판단하지 않는다.
