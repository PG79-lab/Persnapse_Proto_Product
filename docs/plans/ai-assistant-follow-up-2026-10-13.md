# AI 어시스턴트 후속 개선 목록

기준일: 2026-10-13. 핵심 구축 이후의 후속 항목이며 추가 구현·유료 평가를 승인한 문서가 아니다.

| 우선순위  | 항목                                               | 다음 확인/개선                                                                                                                      |
| --------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| P0 통합   | 다른 세션 변경과 원본 통합                         | 공통 파일·legacy 삭제 유지, 통합 상태의 핵심 UX 점검                                                                                |
| P0 운영   | 독립 DB migration, backfill, worker/scheduler 연결 | 대상·예산·실행 주기 확정, 실제 환경에서 자동 재시도/중단 확인                                                                       |
| P1 품질   | 질문 축약·후속 대화의 추가 live 검증               | 마지막 출력 형식 보정을 재검증. 준비·비교·우선순위에서 대상/기간을 잘못 상속하는 holdout 추가                                       |
| P1 평가   | 더 큰 실제 사용 사례·사용자 평가                   | 설계의 15명/40만남/80사실/30행동 fixture와 단일·다중 turn 평가, 실제 유용성 피드백. 현재 소규모 검증 결과와 구분                    |
| P1 근거   | 의미 수준의 주장 검증                              | 키·소속·날짜·상태 확인 외에 실제 문장 의미와 근거의 일치 평가, 충돌하는 기록의 설명 개선                                            |
| P1 입력   | 사실·맥락·원문 연결의 누락 점검                    | 다양한 텍스트/전사/OCR 검토 사례, 불확실한 상대 날짜·인물 및 장문의 근거 보존                                                       |
| P2 검색   | 한국어·장문·검색 순위 개선                         | 현재 문자열 매칭과 조사 제거의 한계, 문단 기반 chunk, independent keyword/structured ranking, 검색 holdout 및 precision/recall 측정 |
| P2 성능   | workspace 전체 projection refresh 범위 축소        | 현재 statement-level workspace 갱신은 MVP 선택. 원본별 영향 범위 갱신 및 대량 backfill 배치/재개 지점 개선                          |
| P2 비용   | 검색·답변·STT 통합 운영 지표                       | 단계별 지연과 금액 추정, 시간당 한도 외 비용 정책. 기본 경로/확장 답변의 p95 비교                                                   |
| P2 범위   | 인물 없는 일반 업무와 장기 대화                    | 일반 workspace 업무의 독립 근거 계약, 긴 대화 요약/세션 관리. 기존 query 이력의 보존 정책도 함께 검토                               |
| 별도 확장 | 기록/업무 실행·외부 발송·선제 알림                 | 사용자의 검토·확정 흐름과 실행 권한을 설계한 뒤 별도 승인으로 진행                                                                  |

현재 feature flag 기본값은 off이며 원본/원격 환경은 자동으로 바뀌지 않는다. 제품 활성화 상태와 전용 브랜치 구현 상태를 구분한다.
