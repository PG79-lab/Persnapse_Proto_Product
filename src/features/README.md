# Features

웹 프론트 진입점은 `src/app/page.tsx`의 통합 워크스페이스 하나입니다.

| 폴더         | 역할                                          | 화면 연결                                |
| ------------ | --------------------------------------------- | ---------------------------------------- |
| `workspace/` | 메인 화면·메뉴·인맥·지도·업무·녹음·어시스턴트 | `/`과 해시 메뉴                          |
| `capture/`   | 명함 카메라·등록 흐름, 텍스트 기록·검토       | `/#cards` 또는 통합 어시스턴트의 기록 창 |
| `recall/`    | 검색 준비 복구 공통 컴포넌트                  | 통합 어시스턴트 내부                     |

루트의 `card_recognition/`은 명함 복원·뷰어이며 이 앱에서 직접 사용합니다. 기존 독립 프론트와 그 헤더는 제거했습니다. 옛 주소는 `next.config.ts`의 호환 리다이렉트로만 남습니다. API와 서버 처리 코드는 `src/app/api/`, `src/server/`에 있습니다.
